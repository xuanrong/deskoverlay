# DeskOverlay Developer Workspace 产品设计文档 v2.0

## 产品定位

DeskOverlay 是基于 WorkerW 注入技术构建的 Windows 开发者桌面工作台。

核心理念：

> 工作台即桌面。

它不是桌面插件，而是替代传统桌面的个人开发环境。

------------------------------------------------------------------------

## 核心架构

Windows Explorer ↓ WorkerW Desktop Layer ↓ DeskOverlay Runtime ↓
WebView2 ↓ HTML Workspace

------------------------------------------------------------------------

## 设计目标

1.  简洁
2.  高效
3.  低干扰
4.  强提醒
5.  服务开发者工作流

------------------------------------------------------------------------

# 核心模块

## 1. Daily Dashboard

显示：

-   今日目标
-   当前任务
-   工作进度
-   下一提醒

------------------------------------------------------------------------

## 2. Developer Task System

区别普通 Todo：

支持：

-   项目关联
-   Git Branch
-   Deadline
-   状态管理

状态：

Coding / Testing / Review / Done

------------------------------------------------------------------------

## 3. Project Monitor

监控：

-   Git状态
-   Build状态
-   服务运行状态
-   Docker容器
-   开发环境

------------------------------------------------------------------------

## 4. Reminder Engine

智能提醒系统。

支持：

### 喝水提醒

根据连续编码时间提醒。

示例：

连续工作90分钟：

"已经工作90分钟，建议喝杯水。"

### 会议提醒

提前：

-   5分钟
-   15分钟
-   30分钟

### 上下班提醒

开始：

显示今日计划。

结束：

生成工作总结。

### 久坐提醒

检测键鼠活动。

------------------------------------------------------------------------

# 工作模式

## Coding Mode

显示：

-   当前项目
-   Git状态
-   任务
-   计时器

## Meeting Mode

显示：

-   会议
-   文档
-   快速记录

## Focus Mode

只显示：

-   当前任务
-   专注计时

## After Work Mode

显示：

-   今日总结
-   明日计划

# AI Assistant

AI 不作为聊天工具。

而是工作流助手。

能力：

-   自动整理任务
-   分析代码工作状态
-   生成日报
-   调整工作空间
